Artist is a Kind, not a field reached only through Album — the album’s artist is nullable, so an album-only path accumulates records with nobody behind them, and following somebody whose records you do not own yet is a thing people do. Within Album the Artist field still creates one inline, so the common path stays one form. Tracks is a count, never eleven rows of 4:12 — a tracklist typed by hand often has names and no timings. First heard is stored, not derived: deriving it would report yesterday for a record somebody has had since 2011.
