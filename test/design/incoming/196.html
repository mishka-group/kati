The recommendation, and what it costs
The anchored panel, not a bottom sheet. A sheet in this app is a task — Log a listen, New goal, Your country, Quick add — with a title and a close button. A menu is a short list of doors. If money’s … rises as a sheet while Schedule’s drops a panel, the same glyph means two different things depending on which root you are standing in. This board ratifies the panel the code already ships on 02, 03, 04, 08 and 43 — ink no drawing had ever approved.
